## 一、项目概述

一个部署在 GitHub Pages 上的五笔学习网站：免费、免安装、打开即练，纯静态、无后端。

**输入法标准**：V1 仅支持微软五笔（其单字编码即 86 版王码），码表以 RIME 开源 wubi86 码表为唯一事实源。架构预留多方案扩展点，后续版本依次支持 98 版、新世纪（06 版）王码与双拼（微软双拼 / 小鹤双拼）。

## 四、架构与核心设计

### 4.1 分层与数据流

```
视图层（views/components）  ──键盘事件──▶  引擎（engine，纯函数）
        ▲                                    │
        └──── ref(session) 响应式渲染 ◀──────┘  返回新状态 + 事件列表
                     │
        事件（char-error 等）──▶ composables（错题记录、进度持久化）
```

- 引擎为纯函数：不依赖 DOM、Vue、定时器，可独立单测。
- 视图层以 `ref` 持有会话状态，每次 `feedKey` 后整体替换触发渲染。
- 计时由视图层驱动：每秒调用一次 `calcStats(session, Date.now())`，引擎不内置定时器。

### 4.2 输入方案接口（`src/schemes/base.ts`）

练习引擎仅依赖此接口，不感知五笔细节。98 / 新世纪 / 双拼的接入 = 新增接口实现 + 新内容源，引擎与视图零改动。

```ts
/** 单个提示单元：五笔为字根，双拼为声母 / 韵母 */
export interface HintItem {
  text: string   // 显示文本，如 "女"、"声母 h"
  key: string    // 对应键位，如 "v"
}

export interface InputScheme {
  readonly id: 'wubi86' | 'wubi98' | 'wubi06' | 'doublepy-ms' | 'doublepy-flypy'
  /** 目标字符的标准全码（判定基准） */
  code(char: string): string | null
  /** 目标字符的可用简码列表（用于空格上屏），无简码返回空数组 */
  shorts(char: string): string[]
  /** 拆解提示（渲染用） */
  hint(char: string): HintItem[]
}
```

### 4.3 练习引擎（`src/engine/`）

**API（签名固定）**

```ts
export type CharState = 'pending' | 'active' | 'done'

export interface PracticeItem {
  char: string
  code: string
  state: CharState
  wrongAttempts: string[]   // 本字每次出错时已输入的内容快照
}

export interface PracticeSession {
  items: PracticeItem[]
  cursor: number            // 当前字下标
  input: string             // 当前字已接受的输入
  correctKeys: number
  totalKeys: number
  correctChars: number
  startAt: number           // 由调用方传入的时间戳
  finished: boolean
}

export type EngineEvent =
  | { type: 'key-accept' }
  | { type: 'key-reject'; expect: string; actual: string }
  | { type: 'char-done'; char: string }
  | { type: 'char-error'; char: string; expect: string; actual: string }
  | { type: 'session-done' }

export function createSession(chars: string[], scheme: InputScheme, now: number): PracticeSession
export function feedKey(session: PracticeSession, key: string): { session: PracticeSession; events: EngineEvent[] }
export function calcStats(session: PracticeSession, now: number): { speed: number; accuracy: number; elapsedSec: number }
```

**判定规则（固定，不得变更）**

1. 仅响应 `a-z` 与空格；其余按键（含 Backspace）一律忽略。
2. 字母键：若 `input + key` 是当前字全码的前缀 → 接受（`key-accept`，`totalKeys + 1`、`correctKeys + 1`）；否则拒绝（`key-reject` + `char-error`，已接受输入保留不变，`totalKeys + 1`）。
3. 空格键：若当前 `input` 非空且等于该字某个简码 → 完成该字（`char-done`）；否则视为错键，按规则 2 的拒绝路径处理。
4. 全码输满（`input === code`）自动完成该字，无需空格。
5. 字完成 → 光标前进；最后一字完成 → `session-done`、`finished = true`。
6. 提示常驻：界面始终显示当前字的全码与拆解（学习产品，允许照抄过关）。
7. 不支持退格修改：V1 刻意简化，错键只计数不污染已接受输入。

### 4.4 统计口径（固定）

- **速度** = `correctChars ÷ elapsedSec × 60`（字/分钟；字根练习为正确击键数/分钟），每秒刷新。
- **正确率** = `correctKeys ÷ totalKeys`，按键级口径；`totalKeys = 0` 时显示 100%。

### 4.5 持久化（localStorage）

| 键 | 内容 | 写入时机 |
|---|---|---|
| `wubi.v1.progress` | 解锁列表 + 每关最佳成绩 | 关卡通过时 |
| `wubi.v1.mistakes` | 单字错题本 | 每次 `char-error` |

## 五、数据结构（`src/types.ts`）

```ts
/** 单字码表条目（脚本生成） */
export interface CharEntry {
  code: string                      // 全码，如 "vb"
  short: string[]                   // 简码层级，如 ["v", "vb"]
  radicals: [string, string][]      // 拆字：[字根, 键位]，如 [["女","v"],["子","b"]]
  freq: 0 | 1                       // 1 = 通用规范一级 3500 字
}

/** 关卡配置（src/data/levels.ts 静态定义） */
export interface LevelConfig {
  id: string                        // 如 "zigen-heng"
  type: 'zigen' | 'danzi'
  title: string                     // 如 "横区字根（G F D S A）"
  pool: string[]                    // zigen：键位列表；danzi：忽略
  source?: 'short1' | 'short2' | 'freq1'   // danzi 出题池
  starts?: string[]                 // danzi 出题首码过滤（按区分关用）
  length: number                    // 出题数量
  require: { speed: number; accuracy: number }
}

/** 进度 */
export interface ProgressData {
  unlocked: string[]
  best: Record<string, { speed: number; accuracy: number; at: number }>
}

/** 错题本（仅单字；字根错误仅存于会话级，见 6.4） */
export type MistakeBook = Record<string, {
  code: string
  count: number
  lastWrongInputs: string[]         // 最近最多 5 条
  lastAt: number
  mastered: boolean
}>
```

**内置数据表**：一级简码 25 字（G一 F地 D在 S要 A工 / H上 J是 K中 L国 M同 / T和 R的 E有 W人 Q我 / Y主 U产 I不 O为 P这 / N民 B了 V发 C以 X经）；二级简码由码表的两位编码导出；86 版五区字根口诀表（`scripts/sources/zigen.json`，25 键位：键名、口诀、字根列表）。

**数据源说明（实现确定）**：

- 编码事实源：RIME `rime/rime-wubi` 的 `wubi86.dict.yaml`。同一字多编码时取最长码为全码（`code`），其余为简码（`short`）。
- 字根拆解：`hantang/search-wubi` 的 `data-wubi-v86.tsv`，字根以私有区（PUA）码点序列存储；经 `scripts/sources/roots-map.json` 映射为字根文本，键位由全码对齐。未收录的 PUA 按键名字根兜底。
- 分级依据：`data-chars.tsv` 中 `level = 一级` 判定常用 3500 字。
- 关卡题量 `length`：字根关 20，一级简码关 12，其余单字关 20。
- 拆字字段 `radicals` 的键位恒为全码前缀（校验①保证）；识别码位按对应键位字根展示，属已知近似，留待 V1.1 精修。

## 六、功能规格

### 6.1 关卡选择与解锁

- V1 关卡序列：字根 5 关（横/竖/撇/捺/折）→ 一级简码 2 关 → 二级简码 4 关（按区）→ 常用字 4 关，共 15 关，`levels.ts` 静态定义。
- 首关默认解锁；第 N 关达标（速度 ≥ 阈值 **且** 正确率 ≥ 阈值）解锁第 N+1 关。
- 阈值：字根关 15 键/分、正确率 90%；一级简码 20 字/分；二级简码 25 字/分；常用字 20 字/分；单字关正确率统一 85%。
- 列表项展示：标题、达标要求、最佳成绩、锁定状态。

### 6.2 字根练习（ZigenView + KeyboardMap）

- 顶部：速度、正确率、进度（n/N）。
- 中部 `KeyboardMap`：5×5 键位图，每格显示键名与口诀；系统随机高亮一格等待按键。
- 判定：按对 → 绿色反馈、正确 +1、高亮下一格；按错 → 红色闪烁、错误 +1、该键位记入会话错误清单。
- 达 `length` 题量后进入结算（6.4）。

### 6.3 单字练习（PracticeView）

- 顶部：速度、正确率、进度（n/N）。
- `CharLine`：待输入字序列，三态渲染（未输入灰 / 正确绿 / 错误红底）。
- `CodeHint`：当前字全码 + 拆字（`好 → VB（女 V + 子 B）`），常驻显示；已接受的输入部分在编码上高亮。
- 底部 `KeyboardMap`：实时高亮下一个应按键位。
- 判定：严格执行 4.3 规则；`char-error` 事件同步写入错题本。
- 出题：按 `source` 从对应池中随机抽取 `length` 字，不重复（池容量不足时允许重复）。
- 完成全部字后进入结算（6.4）。

### 6.4 结算与错题加练（ResultModal + MistakePicker）

- 结算内容：速度、正确率、用时、是否达标解锁；错误清单（单字：字 / 正确编码 / 最近错误输入 / 次数；字根：错误键位）。
- 清单支持复选与"全选"；点击「加练所选」关闭弹窗并开启加练会话：
  - 内容源 = 选中项，随机排序，每项重复 3 次；复用对应练习视图。
  - 加练结束再次进入结算（可循环）。
- 单字加练中某字**连续 2 次**输入正确 → 错题本标记 `mastered: true`。
- 未选择任何项时可点击「返回关卡」。
