### 1.2 「五笔常用字 606 个」验证结论

**不准确。** 606 的真实含义是**五笔二级简码的数量**（25×25−19=606，86 版；98 版为 613）。
流传说法「这 606 个字基本是日常最常用字」源于经典统计：普通文章中**双字词组（70%）+ 二级简码字（12%）+ 一级简码字（9%）≈ 91%**。

结论与决策：

- 二级简码已在 S2 五区关完整覆盖，S4 不再重复；
- S4 采用项目现成的**一级常用字（通用规范一级字表）3500 个**，按字频降序训练；
- 词组学习的价值由 S5 承载（见第六章），与上述统计一致。

## 三、跟打器设计（核心）

### 3.1 输入模型

- **只比对汉字结果，不关心输入法**：通过隐藏 `<input>` + IME（composition/input 事件）捕获用户提交的汉字字符流；
- IME 组字过程中的拼音字母/候选操作不参与比对、不上屏；仅**提交的汉字**逐字与目标比对；
- **不显示五笔编码、简码、下一步键位提示**（与 S1–S3 的编码判定引擎完全区分）；
- 屏蔽粘贴与拖放（防作弊/防误操作）；
- 测试友好：视图暴露 `feedText(text)` 注入接口，测试无需真实 IME。

### 3.2 判定规则（严格模式）

```
目标：「我 们 的 祖 国」
- 提交字符 === 当前目标字 → 该字标绿，光标前进
- 否则 → 计 1 次错误，错误字以红色显示在当前字位置，光标不前进
  · 用户可退格删除错误字，或直接输入正确字（自动清除错误显示并前进）
- 退格：槽内有错误字 → 清除；槽空 → 已完成字不可回退（无操作）
- 全部完成 → 结算
```

- 首次提交之日起开始计时；结算用时包含错误与退格时间（天然惩罚出错）；
- 速度（字/分）= 已正确字数 × 60000 ÷ 用时；实时刷新；
- 正确率 = 1 − 错误提交 ÷ 总提交字符数；
- 快捷键：Esc 重开本组/本节；输入框自动聚焦，点击练习区重新聚焦。

### 3.3 统计指标（跟打器标准口径）

| 指标 | 含义 |
|---|---|
| 速度（字/分） | 正确字数 ÷ 用时 |
| 击键（键/分） | 物理按键数 ÷ 用时；统计真实按键（含 IME 组字期间的字母、数字选字、空格与退格），如实反映用户所选输入法的按键负担（V3.3 恢复） |
| 正确率 | 1 − 错误提交 ÷ 提交总数 |
| 错误字清单 | 目标字 + 错误输入（最多展示 20 条） |

> V3.1 曾移除键频 / 码长 / 热力图；V3.3 按需求恢复「击键」指标（不含码长与热力图），见 15.5。

### 3.4 虚拟键盘与输入体验（V3.1）

- 练习区底部使用与 S1–S3 相同的虚拟键盘（`VirtualKeyboard.vue`）：**逐键渲染字根矩阵与一级简码**（随当前方案加载）；物理按键按下时对应键帽点亮反馈（180ms 自动熄灭），不做下一步高亮（不关心输入法）；
- **文本光标**：当前待输入字处显示闪烁光标，输入完成自动前进；
- **IME 候选框定位**：隐藏输入框绝对定位于当前待输入字（随滚动、换组、窗口缩放同步），输入法候选框跟随该位置出现；
- **拆字提示卡片**：复用 `CodeHint.vue`，实时显示当前字的五笔字根拆解与全码（跟打参考用，可全局隐藏）；
- **对齐切换**：流式布局提供居中 / 左对齐按钮（与编码练习关共用全局设置）；诗词冲刺与古韵提速关进入时默认居中，网格布局（爬坡 / 毕业综合）不显示切换按钮；
- **排版保留**：自由模式与耐力关按原文渲染标点与段落换行（标点仅显示、不参与跟打）。

### 3.5 跟打器不计入

- 不写入单字统计（`CharStat`）与错题本（`MistakeBook`）——两者为编码语义；
- 不写关卡进度 → 自由模式仅本局统计展示。

### 5.2 爬坡机制（V3.2 连续训练）

- **每组 10 字，顺序固定不随机**（通关前字序恒定，保证可重复训练形成肌肉记忆）；
- **通关速度档位：35 / 50 / 70 字/分单选（默认 50）**，练习页可随时切换，当前组判定按所选档实时生效；
- **达标条件：本组全部正确完成，且用时 ≤ 组内字数 × 60 ÷ 所选档速度**（计时从本组首次提交起，至最后一字完成为止，包含错误退格耗时）；
- **连续训练，不出结算卡片**：达标 → 横幅提示成绩后自动进入下一组；不达标 → 横幅提示并自动重来本组；
- 练习页显示说明文字「速度达 XX 字/分自动进入下一组，未达标自动重来」；
- 可**回打任意已完成组**复习（不影响进度）；未解锁组不可跳过；
- 全部组达标 → 本关通关（写入 `LevelResult`，`bestSpeed` = 最佳单组速度，段位按所选档位计算）；
- 每组最佳速度记录并展示（组进度格 tooltip）。

### 5.3 关内进度与重新随机

- 进度保存：`typing[levelId] = { groupIndex, shuffleSeed?, groupBests }`（见第十章）；
- **重新随机**：关卡内右上角按钮 → 确认「将打乱本关 700 字顺序并清除本关进度」→ 生成随机种子重排；默认练习顺序为字频序（最常用在前）；
- 地图卡片显示关卡进度（如 `23/70 组`）。

// src/engine/typing.ts
export interface TypingSession {
  target: string[]
  pos: number                  // 已正确提交字数
  errorSlot: string | null     // 当前位置错误显示
  errors: { index: number; input: string; at: number }[]

  startAt: number | null

}
export type TypingEvent =
  | { type: 'correct'; index: number; char: string }
  | { type: 'wrong'; index: number; input: string }
  | { type: 'backspace' }
  | { type: 'complete' }
export function createTypingSession(target: string[]): TypingSession
export function feedChar(s: TypingSession, char: string, now: number): { session: TypingSession; events: TypingEvent[] }
export function feedBackspace(s: TypingSession, now: number): { session: TypingSession; events: TypingEvent[] }
export function feedText(s: TypingSession, text: string, now: number): { session: TypingSession; events: TypingEvent[] }
export function typingStats(s: TypingSession, now: number): { speed: number; accuracy: number; elapsedMs: number; done: number; total: number; finished: boolean }
