# 字根标注器（Root Tagger）

人工把字体私有区（PUA）中的字根字形分配到 25 个字母键，并编辑每个按键的字根排布矩阵，
产出键盘渲染配置，用于重做 86 / 98 两套五笔的字根键盘表。

- **字根分配**：`{键: [字根字形数组]}`（字根列表数据，用于随机练习等）
- **布局编辑**：每个键 4×4 / 5×5 矩阵的摆放配置（键盘外观渲染）

## 启动

需要用本地静态服务器打开（浏览器对 `file://` 加载字体有 CORS 限制）：

```bash
# 项目根目录执行（前台运行，关闭终端即停止）
python -m http.server 8765 --directory tools/root-tagger
# 或
npx serve tools/root-tagger -l 8765
```

Windows 下希望**关闭终端后服务继续运行**（避免标注中途服务停止）：

```powershell
# 项目根目录执行，路径按实际情况替换
Start-Process python -ArgumentList '-m','http.server','8765','--directory','E:\Work\Web\五笔学习\tools\root-tagger' -WindowStyle Hidden
```

浏览器访问 <http://localhost:8765/>。若页面打不开，先确认服务是否在运行
（`curl http://localhost:8765/` 或重新执行上面的启动命令）。

> **页面交互异常时先强制刷新**（Ctrl + F5）。`index.html` 里的资源引用带 `?v=` 版本号，
> 修改 `app.js` / `style.css` / `data/*.js` 后请递增版本号，避免浏览器缓存旧脚本
> 导致交互失效（脚本检测到页面与代码版本不一致时也会提示强制刷新）。

## 界面布局

四栏常驻，从左到右：

```
[字母键] [字根卡片池] [当前键字根列表] [布局编辑]
  170px      330px         235px        自适应
```

### 字根分配（前两栏）

1. **选键**：点击左侧字母键（或直接按键盘 A-Y），进入该键的编辑状态
2. **分配字根**：在中间卡片池点击字形卡片
   - 未分配的卡片 → 加入当前键
   - 已属于当前键的卡片 → 点击移除
   - 已属于其他键的卡片 → 点击移入当前键（卡片状态唯一）
3. **调整顺序**：右侧「当前键的字根」列表可拖拽排序（布局自动填充按此顺序）
4. **过滤**：
   - `只看建议属于当前键`：只显示统计建议归属当前键的卡片（高效逐键确认）
   - `只看未分配`：找出还没归属的字形
   - `隐藏识别码`：默认开启，识别码符号（圆圈）不参与字根表
   - `显示空白字形`：86 字体中大量空白码点默认隐藏
   - 搜索框支持码点（如 `F0086`）、例字（如 `工`）、文本
5. **底栏**：鼠标悬停卡片显示大字预览、码点、例字、键位投票明细

推荐的标注流程：选键 → 勾选「只看建议键」→ 逐张确认 → 关闭过滤处理零星未分配卡片。

### 布局编辑（第四栏）

在右侧键帽矩阵中编辑当前键的字根排布：

- **矩阵尺寸**：4×4 或 5×5（切换时放不下的字根会提示移除）
- **拖入**：从右侧列表拖字根到格子
- **交换**：拖动格子内的字根到另一个格子
- **标记**：右键格子打开标记菜单，三个独立开关可组合：
  - 加粗（细线字根以描边加粗）
  - 标红 / 标绿（仅作为标记类型导出，编辑器内为预览色，实际渲染色值由消费方按深色/浅色主题决定）
- **移除**：把格子里的字根拖回右侧列表
- **自动填充**：按字根列表顺序填满矩阵
- 键帽淡灰渐变模拟按键外观；已放入矩阵的字根在右侧列表带绿点标记
- 键盘矩阵配置与字根列表独立保存，共用 localStorage 与导入/导出

## 调试日志

拖拽异常时，按 **`` ` ``**（反引号）开关右下角日志浮层（或访问 `?debug=1`）：

- 记录 `dragstart`（来源/码点）、`dragover`（目标）、`drop`（数据）、`handleCellDrop`（处理结果与数据来源）
- 也可按 F12 在 console 查看 `[RT]` 日志，或输入 `__rtLog` 查看历史
- 拖拽数据通过内存变量传递（`来源: 内存`），不依赖浏览器 `dataTransfer.getData`
  （部分环境下该数据会在 drop 时丢失，导致"拖拽无效"）

## 数据说明

- **98 版**：369 个字形（U+F0000-F0170），自然语言建议来自 98 码表 + 拆解数据的按位投票
- **86 版**：671 个字形（U+E000-E864，其中空白 269 个隐藏、识别码 15 个），预填来自现有
  `scripts/sources/zigen-glyphs.json` 配置
- 标注进度自动保存在浏览器 localStorage（每方案独立），可随时关闭页面继续
- 「按建议重置」会用统计数据重新预填（覆盖当前手工修改，慎用）

## 导出

点击「导出」下载字根表 `wubi98-zigen.json` / `wubi86-zigen.json`：

```json
{
  "scheme": "wubi98",
  "label": "98王码",
  "names": { "a": "工", "b": "子", "...": "..." },
  "short1": { "a": "工", "b": "了", "...": "..." },
  "roots": { "a": ["工", "戈", "...": "..."], "b": ["子", "...": "..."] }
}
```

在布局编辑模式点击「导出布局」下载 `wubi98-layout.json` / `wubi86-layout.json`：

```json
{
  "scheme": "wubi98",
  "layouts": {
    "a": {
      "size": 5,
      "cells": [{ "cp": "工", "bold": true, "mark": "red" }, null, "...": "..."]
    }
  }
}
```

- `cells` 长度 = `size × size`（行优先），`null` 为空位
- `bold`：加粗标记；`mark`：`"red" | "green" | null`，仅表示标记类型，
  具体色值由渲染方按深色/浅色主题决定（不存颜色值）
- 仅导出编辑过的键；`cp` 为 PUA 字符（与 `roots` 一致）
- 两种文件都可通过「导入」按钮恢复（自动识别 `roots` / `layouts` 字段）
- 主项目构建脚本读取这两个文件补全分区/口诀后生成最终键盘渲染配置

## 数据重新生成

源数据（码表、拆解数据、字体）更新后，重新生成 `data/*.js`：

```bash
python tools/root-tagger/scripts/build-data.py
```

脚本会输出每套方案的卡片数、非空数、投票覆盖、识别码候选清单，并检测
「拆解数据用到但字体缺失」的字形。
